How it works

  1. IngestPython pulls hourly weather and air quality for 6 cities from the free Open-Meteo APIs, with retries and backoff, and appends the raw rows to Bronze in DuckDB.
  2. Transformdbt builds Silver with an incremental model that keeps the latest record per city and hour, using a watermark with a lookback window, then Gold marts with AQI and heat index bands.
  3. Testdbt tests (unique keys, not-null, accepted values and ranges), source freshness and a Bronze-to-Gold row-count reconciliation. Results feed this panel.
  4. PublishGold is exported to small JSON files and published by GitHub Actions every hour. A failed run opens a GitHub issue.

Stack: Python · DuckDB · dbt · sqlfluff · pytest · GitHub Actions · Plotly. Running cost: ₱0.
