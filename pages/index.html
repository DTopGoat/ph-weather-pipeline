PH Weather & Air Quality Pipeline

This GitHub Pages site is the hourly data endpoint for the pipeline. The app lives at Thy Weather (thy-weather.netlify.app).

Published Gold files (refreshed every hour by GitHub Actions):

  • data/pipeline_health.json – last run, rows loaded, tests, freshness
  • data/current.json – latest observed hour per city
  • data/cities.json, data/reference.json
  • data/city/<city_id>.json – hourly (past 7 days + forecast) and daily rollups
  • data/dq_results.json – data quality results for the last run

Source: github.com/DTopGoat/ph-weather-pipeline. Data by Open-Meteo.com (CC BY 4.0).
